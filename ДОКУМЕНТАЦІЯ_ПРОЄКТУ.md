# Документація до шкільного проєкту "Модель Сонячної системи"

## Огляд проєкту

Цей проєкт є інтерактивною 3D моделлю Сонячної системи, розробленою як шкільний проєкт з використанням движка Ursina. Модель відтворює реальні орбітальні рухи планет навколо Сонця з візуальним представленням орбіт та можливістю вільного навігування камерою.

### Особливості проєкту

- **Повна Сонячна система**: Містить Сонце та всі 8 планет з реалістичними текстурами
- **Візуалізація орбіт**: Тонкі білі кільця, що показують орбіти планет
- **Вільна камера**: Інтуїтивне керування (обертання, зум, панорамування мишею)
- **Реалістичні швидкості**: Повільні, реалістичні орбітальні та обертальні швидкості
- **Темний фон космосу**: Аутентичний темний простір замість сірої сітки
- **Інтерактивні керування**: Включення/виключення орбіт, скидання камери

## Структура проєкту

### Основні файли та папки

#### 📁 Коренева папка проєкту
- `main.py` - головний файл програми з основним кодом симуляції
- `main_test.py` - тестова версія головного файлу (дубль основного)
- `README.md` - інструкція для користувача англійською мовою
- `requirements.txt` - залежності проєкту (використовується лише ursina)
- `.gitignore` - файл ігнорування для Git

#### 📁 config/ - Конфігураційні налаштування
- `settings.py` - головний файл налаштувань всіх параметрів системи
  - Розміри та текстури Сонця та планет
  - Радіуси орбіт та швидкості руху
  - Кольори та параметри візуалізації орбіт
  - Налаштування камери та фону

#### 📁 systems/ - Системи логіки програми
- `planet_orbit.py` - система орбітальних рухів планет
  - Функції оновлення позицій планет
  - Обертання навколо власної осі
  - Скидання орбіт до початкових позицій
- `orbits.py` - система створення та керування кільцями орбіт
  - Генерація вершин для кілець орбіт
  - Візуалізація орбіт як плоских кілець
  - Керування видимістю орбіт
- `lighting.py` - система освітлення з Сонцем як основним джерелом світла
  - Створення джерела світла
  - Налаштування інтенсивності світла
  - Керування тінями

#### 📁 scenes/ - Управління сценами
- `__init__.py` - функції для завантаження конфігурації сцен
  - Завантаження JSON конфігурації
  - Застосування налаштувань камери
  - Застосування налаштувань сцени

#### 📁 assets/ - Ресурси проєкту
- `textures/` - текстури для Сонця та планет
  - Сонце, Меркурій, Венера, Земля, Марс
  - Юпітер, Сатурн, Уран, Нептун
- `materials/` - матеріали для об'єктів (майбутнє використання)

#### 📁 __pycache__/ - кеш Python (автоматично створюється)

## Як працює модель Сонячної системи

### Принципи орбітальної механіки

1. **Центральне тіло** - Сонце розташоване в центрі системи з розміром 2.0 одиниць
2. **Орбітальні рухи** - Кожна планета рухається по круговій орбіті навколо Сонця
3. **Потрійне рухування**:
   - Орбітальний рух навколо Сонця
   - Обертання навколо власної осі
   - Різні швидкості для кожної планети

### Параметри планет

| Планета | Радіус орбіти | Розмір | Швидкість орбіти | Швидкість обертання |
|---------|---------------|--------|------------------|---------------------|
| Меркурій | 4.0 | 0.2 | 1.6 | 0.5 |
| Венера | 6.0 | 0.3 | 1.2 | 0.4 |
| Земля | 8.0 | 0.3 | 1.0 | 0.4 |
| Марс | 10.0 | 0.25 | 0.8 | 0.3 |
| Юпітер | 15.0 | 0.8 | 0.5 | 0.2 |
| Сатурн | 20.0 | 0.7 | 0.4 | 0.2 |
| Уран | 25.0 | 0.5 | 0.3 | 0.2 |
| Нептун | 30.0 | 0.5 | 0.2 | 0.2 |

### Алгоритми роботи

#### Головний цикл
1. **Ініціалізація** - створення Сонця, планет та орбітних кілець
2. **Головний цикл** - постійне оновлення позицій планет відносно часу
3. **Обробка вводу** - реагування на натискання клавіш

#### Математичні обчислення
- Використання тригонометрії для обчислення позицій планет
- Мультиплікатори швидкостей для реалістичного руху
- Плавна інтерполяція між кадрами

## Встановлення та запуск

### Необхідне ПЗ
- Python 3.8 або вище
- Бібліотека Ursina Engine

### Інструкція з запуску
1. Встановіть Ursina: `pip install ursina`
2. Запустіть програму: `python main.py`

### Керування

#### Клавіатура
- **ESC** - вихід з симуляції
- **R** - скидання орбіт планет
- **O** - перемикання видимості орбіт
- **C** - скидання позиції камери
- **H** - довідка

#### Миша
- **Правий клік + переміщення** - обертання камери
- **Колесо миші** - зум
- **Середній клік + переміщення** - панорамування
- **WASD/QE** - політ (з утримуванням правого кліку)

## Наукові аспекти проєкту

### Відповідність реальності
Хоча модель спрощена, вона дотримується основних принципів:
- Планети рухаються від Сонця відповідно до їх реальної відстані
- Внутрішні планети рухаються швидше за зовнішні
- Розміри планет відповідають їх відносним розмірам

### Обмеження моделі
- Орбіти ідеально круглі (у реальності - еліптичні)
- Не враховуються гравітаційні взаємодії між планетами
- Не показується пояс астероїдів та інші небесні тіла

## Розширення проєкту

Можливі подальші вдосконалення:
- Додавання місяців планет
- Реалістичні еліптичні орбіти
- Фізика гравітації
- Інформаційні панелі про планети
- Звукові ефекти
- Режим з реальними маштабами
