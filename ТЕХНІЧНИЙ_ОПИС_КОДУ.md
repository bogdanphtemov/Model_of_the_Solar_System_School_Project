### 📄 systems/planet_orbit.py - Система орбітального руху

#### Функція `update_planets(planet_entities, time_delta)`
**Призначення**: Оновлення позицій та обертання планет

**Алгоритм роботи:**
1. Для кожної планети в `PLANETS_DATA`:
2. Перевіряє наявність сутності планети
3. Оновлює орбітальний кут: `angle += speed * time`
4. Обчислює нову позицію за формулою:
   - `x = cos(angle) * radius`
   - `z = sin(angle) * radius`
5. Оновлює обертання навколо осі Y

**Математичні формули:**
- Положення на орбіті: `(cos(θ)*r, 0, sin(θ)*r)`
- Обмеження кута: `θ %= 2π`

#### Функція `reset_all_orbits(planet_entities, initial_angles=None)`
**Призначення**: Скидання всіх планет до початкових позицій

**Логіка розподілу планет:**
- Рівномірний розподіл навколо Сонця
- Кожна планета на іншому початковому куті
- Формула: `angle = (2π / n) * index`

### 📄 systems/orbits.py - Система орбітних кілець

#### Функція `orbit_ring_vertices(radius, width, segments)`
**Призначення**: Генерація вершин для кільця орбіти

**Геометрія кільця:**
- Два концентричних кола (зовнішнє та внутрішнє)
- Створення кіл з `segments` сегментів
- З'єднання вершин трикутниками

**Формула генерації:**
- Зовнішнє коло: `(cos(θ)*r, 0, sin(θ)*r)`
- Внутрішнє коло: `(cos(θ)*(r-w), 0, sin(θ)*(r-w))`

#### Функція `create_orbit_ring(radius, name)`
**Призначення**: Створення об'єкта орбітного кільця

**Властивості кільця:**
- Модель: спеціально згенерована сітка
- Колір: білий з прозорістю
- Unlit: не реагує на освітлення
- Double-sided: видиме з обох сторін

#### Функція `set_orbits_enabled(orbit_entities, enabled)`
**Призначення**: Увімкнення/вимкнення видимості орбіт
- Встановлює властивість `enabled` для всіх кілець

### 📄 systems/lighting.py - Система освітлення

#### Функція `create_sun()`
**Призначення**: Створення Сонця як джерела світла

**Структура об'єкта Сонця:**
- Геометрія: сфера
- Текстура: зображення Сонця
- Джерело світла: PointLight як дочірній об'єкт

**Параметри світла:**
- Колір: теплий білий (RGB: 255, 242, 204)
- Інтенсивність: масштабована для Ursina
- Дальність: 100.0 одиниць

#### Функція `setup_scene_lighting()`
**Призначення**: Налаштування загального освітлення сцени
- Встановлює колір фону вікна
- Створює та повертає Сонце

- При відсутності - використовує конфігурацію за замовчуванням
- Обробляє помилки парсингу JSON

**Призначення**: Застосування налаштувань камери

**Призначення**: Застосування налаштувань сцени

## Архітектура проєкту

### Співвідношення між модулями

```
main.py
├── config.settings (налаштування)
├── systems.planet_orbit (рух планет)
├── systems.orbits (візуалізація орбіт)
└── scenes (управління сценою)
```

### Принципи проектування

1. **Розділення відповідальності**: Кожен модуль виконує одну основну функцію
2. **Конфігураційний файл**: Всі параметри зосереджені в одному місці
3. **Модульність**: Можливість легко додавати нові функції
4. **Гнучкість**: Легка зміна параметрів через settings.py

### Ключові технології

- **Ursina Engine**: 3D графіка та інтерактивність
- **Python 3**: Основний мова програмування
- **Математика**: Тригонометрія для орбітальних обчислень
- **Об'єктно-орієнтоване програмування**: Структуровані сутності
