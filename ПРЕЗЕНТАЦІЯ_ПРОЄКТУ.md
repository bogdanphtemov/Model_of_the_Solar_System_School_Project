# Презентація шкільного проєкту "Модель Сонячної системи"

## Короткий огляд для вчителя

### Що це за проєкт?
Це **інтерактивна 3D модель Сонячної системи**, розроблена як шкільний проєкт. Програма дозволяє візуалізувати рух планет навколо Сонця з реалістичними орбітами та можливістю вільного навігування в просторі.

### Основні цілі проєкту
- Навчитися створювати 3D графіку за допомогою Python
- Зрозуміти принципи орбітальної механіки
- Розвинути навички програмування та математичного моделювання
- Показати взаємодію між програмуванням та фізикою

## Науковий зміст

### Відтворені явища
- **Рух планет навколо Сонця** - реалізовано з використанням тригонометрії
- **Різні швидкості руху** - внутрішні планети рухаються швидше за зовнішні
- **Обертання планет** - кожна планета обертається навколо своєї осі
- **Візуалізація орбіт** - тонкі кільця показують траєкторії руху

### Навчальна цінність
- **Математика**: використання синусів/косинусів для обчислення позицій
- **Фізика**: принципи орбітального руху, центростремительні сили
- **Програмування**: об'єктно-орієнтоване програмування, 3D графіка
- **Астрономія**: відносні розміри та відстані в Сонячній системі

## Технічні особливості

### Використані технології
- **Мова програмування**: Python 3
- **Графічний рушій**: Ursina Engine
- **Математика**: тригонометричні функції для обчислення орбіт
- **Архітектура**: модульна структура з чітким розділенням функцій

### Ключові функції
```plaintext
☀️ Сонце як центральне тіло
🪐 8 планет з різними параметрами
🔄 Автоматичний орбітальний рух
👁️‍🗨️ Вільне керування камерою
⚙️ Гнучкі налаштування швидкостей
🎯 Інтерактивні керування (ESC, R, O, C, H)
```

## Як демонструвати проєкт

### Запуск програми
1. Встановити Python 3.8 або вище
2. Встановити бібліотеку: `pip install ursina`
3. Запустити: `python main.py`

### Демонстрація можливостей
1. **Автоматичний рух** - показати, як планети рухаються самі
2. **Керування камерою** - продемонструвати вільне навігування
3. **Перемикання орбіт** - показати/приховати кільця орбіт (клавіша O)
4. **Скидання позицій** - скинути планети до початкового положення (R)
5. **Інформація** - вивести довідку про керування (H)

### Пояснення наукових основ
- Чому внутрішні планети рухаються швидше?
- Як обчислюються позиції планет у кожен момент часу?
- Яке значення мають параметри у файлі settings.py?

### Кодова структура
Проєкт має чітку модульну структуру:
- `main.py` - головна логіка
- `config/settings.py` - всі параметри
- `systems/` - окремі системи (рух, освітлення, орбіти)
- `scenes/` - управління сценами
